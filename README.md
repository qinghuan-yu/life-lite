# 一水生活 0.3.1 测试版

Android 精简客户端，集中使用慧生活798接水和住理生活联网洗浴。正常使用平台账号、权限和原费率，不改变金额、签约状态或服务器鉴权。

**慧生活798支付宝快捷登录已在用户手机上验证成功，重启后会话仍有效。** 真实接水、洗澡、免密签约及扣款闭环尚未验收；登录成功不代表已经验证扣款。

下载：[GitHub Releases](https://github.com/qinghuan-yu/life-lite/releases)。安装包、源码压缩包和SHA-256校验文件随测试版提供。

## 本版改动

- 登录入口明确标注支付宝：未登录时显示「支付宝登录」；已登录时位于「我的 → 慧生活798 → 支付宝重新登录」，无需先退出账号。

- 新增支付宝快捷登录作为默认入口：SDK 正常授权、一次性授权码交换平台会话、读取账户校验身份后保存凭据。短信登录保留为备选。
- 首页保留接水、洗澡、账户、设备和操作；去掉英文标语、宣传句与重复说明。
- 增加按钮按压、页面切换、底部弹窗和提示动画，支持系统减少动态效果。刷新不重建输入框，保留输入及光标。
- 接水确认页按设备返回的 `payItems` 展示支付宝免密（21）和慧生活钱包（91）；支持支付宝时默认选中，不在失败时自动切换扣款渠道。
- 接入支付宝 SDK 的免密签约与账单支付。金额和账单由平台返回，确认前不调用扣款接口。SDK 回调不直接作为支付成功依据。
- 纠正官方应用入口、补充官方二维码域名、兼容数组形态的慧生活账单；登录过期后显示重新登录，保留待确认订单。

## 使用

1. 覆盖安装 `life-lite-0.3.1.apk`，包名为 `cn.qingyu.lifelite`，名称为一水生活。无需卸载旧版。
2. 在「日常 → 接水」点击「支付宝登录」；已有登录会话时，从「我的 → 慧生活798 → 支付宝重新登录」进入。手机需安装支付宝，授权对象为慧生活798；也可切换短信登录。若平台要求绑定手机号，请先在官方应用完成绑定。
3. 住理生活使用原手机号和密码，学校绑定仍在官方应用完成。首版支持联网洗浴设备，设备要求蓝牙时提示返回官方应用。
4. 输入或扫描设备号，查询后核对设备和支付方式，再点击开始。设备实际开始计费后，用结束按钮结束；若平台要求机身结算，请在设备上操作并刷新确认。
5. 免密协议入口位于「我的 → 慧生活798 → 支付宝免密管理」。账单中的支付宝支付会先展示金额，再调用正常付款流程。

支付或启停超时后，应用保留待确认记录，不自动重发。设备空闲不等于账单已支付。无法确认时请在原平台和现场核对；有未确认记录时不要清除数据或卸载。

## 构建

需要 JDK 17、Python 3、Android platform 35、build-tools 35，以及离线测试使用的 `org.json:json:20240303`。本源码包附带 ZXing Core 3.5.3 和支付宝 SDK 15.8.35 的构建库。

从源码目录运行：

```powershell
python -X utf8 build.py --sdk <SDK目录> --work <构建目录> --output <输出APK> --test-json <json-20240303.jar>
node --check assets/app.js
```

SDK 目录可以包含 `android-35/android.jar` 及任意子目录内的 `aapt2.exe`、`zipalign.exe`、`lib/d8.jar`、`lib/apksigner.jar`。构建脚本查找这些文件。

首次构建会在构建目录的 `signing/local-test.p12` 创建本地测试签名。这不是正式发行签名。后续升级必须保留同一签名；本机已经安装的版本使用工作目录中的原签名，源码压缩包不包含私钥或真实账号。

## 架构和数据

- Java 原生层处理 HTTPS 请求、签名、Keystore 加密、扫码和支付宝 SDK；HTML/CSS/JS 仅显示本地界面。
- 慧生活798请求直达 `i.ilife798.com`；住理生活登录请求直达 `pm.whxinna.com`，业务请求使用登录返回的 HTTPS 项目地址。
- 凭据、收藏和待确认订单使用 AES-GCM 与 Android Keystore 保存；不保存密码、短信验证码或支付宝一次性授权码，不参与系统备份。
- 本地页面没有外网脚本。支付宝 SDK 有独立授权/支付页面，与本地业务 WebView 的桥接分离。
- 权限：网络、网络状态、Wi-Fi 状态和扫码相机。网络状态权限用于支付宝 SDK；相机按需请求。
- 支付宝 SDK 在用户调用登录、签约或支付时参与处理，并按支付宝 SDK 规则处理必要的设备、网络及交易信息；不能宣称所有数据始终只留在本机。
